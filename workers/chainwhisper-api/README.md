# ChainWhisper Read API

One public, keyless Cloudflare Worker mounted in front of the existing GitHub Pages site:

`https://chainwhisper.chat/api/v1/*`

The Worker owns only ChainWhisper discovery and public read normalization. It has no wallet, database, account, signing, AES, private-amount, unlisted-order, direct-order, calldata, or generic COTI surface.

Its public, versioned, self-describing read surface follows the useful part of
[Carbon DeFi's public REST API](https://docs.carbondefi.xyz/rest-api/carbon-defi-public-rest-api)
model. Carbon is also the attributed reference-price source; ChainWhisper
independently verifies its own contracts and never delegates execution or
signing to that API.

## Routes

- `GET /api/v1`
- `GET /api/v1/openapi.json`
- `GET /api/v1/status`
- `GET /api/v1/capabilities`
- `GET /api/v1/testnet/registry-v2`
- `GET /api/v1/orders?cursor=0&limit=10`
- `GET /api/v1/orders/{standard|private|recurring|verified-address}/{localId}`
- `GET /api/v1/market-reference?base=p.WISP&quote=p.COTI`
- `POST /api/v1/quote/swap`
- `GET /api/v1/testnet/private-liquidity/pair`
- `GET /api/v1/testnet/private-liquidity/daily-prices?pairKey=0x...&limit=90`

Swap quotes are deliberately limited to one complete visible public ChainWhisper order. Private liquidity, unlisted orders, and direct orders stay local to an authorized signer. If the bounded pair scan or any required order read cannot prove complete coverage, the endpoint refuses the quote instead of claiming a best order. The deployed Worker limits this expensive route to 12 requests per minute per connecting address.

The machine-readable contract is generated from `src/openapi.ts` and served at `GET /api/v1/openapi.json`.

The V2 registry and Private Liquidity V2 routes are present in discovery but
fail closed until both Worker values are configured:

- `CHAINWHISPER_TESTNET_RPC_URL` — the credential-free COTI testnet HTTPS RPC.
- `CHAINWHISPER_TESTNET_CANDIDATE_MANIFEST_JSON` — the exact unified manifest
  generated by the Contracts repository only after all 15 deployments
  re-attest and all 16 owner token admissions are applied. Store this as a
  Worker secret rather than editing `wrangler.jsonc`.

`GET /api/v1/testnet/registry-v2` re-attests all 15 manifest components at the
original attestation block and at a five-block safe head. It returns only the
component key, contract name, address, runtime hash, deployment block, and the
frozen event-policy classification. It never queries or returns logs, event
payloads, ciphertext, private amounts, participant receipts, hidden-intent
identifiers, or wallet activity. The notification policy is equally explicit:
only recipient-addressed `DirectTradeOpened` events qualify as incoming direct
trade/counter notifications; no other trading event does.

Each request rechecks the manifest hash and identities, the canonical
attestation block, Book/module/NFT/private-token runtime hashes at both the
attestation block and safe head, immutable getters and required features. It
then reads every position ID through bounded canonical pages and refuses an
incomplete or duplicated set. The response contains public prices, NFT owner,
revision, availability, contributor count, complete routes, and only the
hidden-intent queue count/cursor. Inventory and hidden side, limit, budget,
minimum fill, and intent IDs are never returned.

`runtimeVerified` covers the registry, public-order read contracts, all eight advertised Privacy Portal bridges, and every advertised private-token contract. The status response also lists what is deliberately outside that scope.

## Verify locally

From `APP`:

```text
node node_modules/typescript/bin/tsc -p workers/chainwhisper-api/tsconfig.json
node node_modules/vitest/vitest.mjs run workers/chainwhisper-api/test
npm run check:api:bundle
```

After the exact all-admissions manifest exists, run the production source and
HTTP route against COTI testnet without starting or deploying a Worker:

```text
CHAINWHISPER_TESTNET_CANDIDATE_MANIFEST_PATH=/absolute/path/to/coti-testnet-unified-candidate.json
CHAINWHISPER_TESTNET_RPC_URL=https://testnet.coti.io/rpc
npm run smoke:api:testnet:readonly
```

The live test is opt-in and is skipped by `npm run test:api`. It allowlists only
`eth_chainId`, `eth_blockNumber`, `eth_getBlockByNumber`, `eth_getCode`, and
`eth_call`, exercises the real `/api/v1/testnet/registry-v2` and
`/api/v1/testnet/private-liquidity/pair` handlers, and verifies complete runtime
identity, event/privacy policy, complete routes, and the absence of private
inventory and hidden-intent fields.

After the daily-price store is deployed and its separate manifest exists, run
the additional read-only analytics rehearsal:

```text
CHAINWHISPER_TESTNET_CANDIDATE_MANIFEST_PATH=/absolute/path/to/coti-testnet-unified-candidate.json
CHAINWHISPER_TESTNET_PRIVATE_LIQUIDITY_ANALYTICS_MANIFEST_PATH=/absolute/path/to/coti-testnet-private-liquidity-analytics.json
CHAINWHISPER_TESTNET_RPC_URL=https://testnet.coti.io/rpc
npm run smoke:api:testnet:analytics:readonly
```

This adds only deployment-receipt reads to the RPC allowlist, calls the real
daily-price handler, and accepts an empty canonical page before the first close.
It never invokes a wallet, recorder, transaction, or write RPC.

The daily-price route separately requires
`CHAINWHISPER_TESTNET_PRIVATE_LIQUIDITY_ANALYTICS_MANIFEST_JSON`. Its exact
manifest must bind the reviewed candidate Book, store deployment receipt,
runtime hashes, features, owner, recorder, and canonical attestation block.
Until configured, the route fails closed with
`503 testnet_analytics_unavailable`. It returns a bounded page containing one
public marginal closing price per completed UTC day plus source provenance.
It never returns depth, inventory, traded amounts, volume, or participants;
the Worker does not replay the recorder's historical derivation and has no
recorder, wallet, or trading authority.

To run the Worker locally with the pinned CLI without adding it to the app:

```text
npm exec --yes wrangler@4.115.0 -- dev --config workers/chainwhisper-api/wrangler.jsonc
```

## Deploy

1. Put `chainwhisper.chat` on a Cloudflare zone and keep its GitHub Pages DNS record proxied.
2. Authenticate Wrangler with a scoped Cloudflare token.
3. Run:

```text
npm exec --yes wrangler@4.115.0 -- deploy --config workers/chainwhisper-api/wrangler.jsonc
```

Only the two `/api/v1` route patterns invoke the Worker. All app paths continue directly to GitHub Pages; no origin proxy code is needed.

`COTI_RPC_URL` and `CARBON_API_BASE_URL` default to public HTTPS endpoints and can be changed as Worker variables. No browser or MCP user receives those backend configuration values.
